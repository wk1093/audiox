Release notes & assets

01 / Fresh install

Start with an SD image

Download the .img.xz for your Pi. Flash it with Raspberry Pi Imager's Use custom option, or choose AudioX in the AudioX Imager fork.

Flashing erases the selected drive. Back up your files first.

02 / Existing device

Update without reflashing

In the AudioX Web UI, open System > Firmware Update. Check for a release, or download the matching .axu here and select it for manual installation.

Your browser needs internet for online downloads. Your Pi does not. Installation validates the archive and reboots the device.

AudioX is a work in progress. Back up your configuration before updating. Report an issue
