A Raspberry Pi audio workstation

Make a Raspberry Pi
part of your setup.

Connect audio devices, route signals, add effects, and trigger sounds from a MIDI controller or the browser. AudioX brings those tools together on a Raspberry Pi.

Get AudioX Setup instructions

Open source and still in development. Images are available for Raspberry Pi 4 and Pi 5; Pi 5 has not yet been tested on hardware.

01 / Routing

Route audio between devices

Send audio from input devices through effects to your outputs. The browser shows the signal connections; the optional display provides meters. USB audio and USB networking let you connect a host computer to the Pi.

02 / Effects

Add effects to your signal path

Use effects including gain, distortion, gate, pitch, and reverb. Save their settings and output levels, and map controls to MIDI.

03 / Soundboard

Play sounds from MIDI or the screen

Upload sounds, assign MIDI notes, choose playback modes, and set controller lighting. Use the browser, MIDI inputs, or the device touchscreen to control it.

04 / Your setup

Keep your settings after a reboot

AudioX saves routing, MIDI, effects, and volume settings. Back up your settings and soundboard files before reinstalling, or install a matching firmware update from the browser.

AudioX is still in development. Stable releases are published manually; Nightly builds include newer changes and may have bugs. Back up your files before updating. Browse the source or contribute on GitHub.

Release notes and files

01 / New installation

Install from an SD card image

Download the .img.xz for your Pi and flash it with Raspberry Pi Imager's Use custom option, or select AudioX in the AudioX Imager fork.

Flashing erases the selected drive. Back up your files first.

02 / Existing installation

Update from the AudioX Web UI

Open System > Firmware Update to check for a release. You can also download the matching .axu here and choose it for manual installation.

The browser needs internet to download a file; the Pi can install it offline. The installer checks the archive and restarts the device.

Back up your settings and soundboard files before updating. Report an issue
