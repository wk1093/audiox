Named Automation Macros

          
Save up to 16 named macros and Run them here, optionally binding a MIDI pad. Only keyboard action plans need USB Keyboard enabled in Config and a connected USB host. Light/MIDI action plans need the selected controller connected. Sound, effects and volume actions do not need either device.

          

            
            
          

          
          

          

            
            
          

          

            
            
          

          
          
Choose a channel/note above, or learn the next pad you press.

          

          

            
            
          

          

          

            
            
          

          
          
Click Record Chord, hold your modifiers, press the key(s), then release. You can also enter CTRL+SHIFT+F13 manually.

          
Captures physical key positions (host layout applies), up to six keys plus Ctrl, Shift, Alt, and Meta/Windows. Letters, digits, F1–F24, Enter, Escape, Tab, Space, Backspace, Delete, arrows and navigation keys are supported. Some system/browser shortcuts cannot be captured; enter those manually.

          

          

            
            
            
tap("CTRL+A"), press("SHIFT+A"), release(), type("Hello!", 80), wait(milliseconds), light(velocity). press replaces the held chord; release clears all keys. Taps/text release any previous hold first; sequence completion/cancellation releases everything automatically. type uses US-layout ASCII (including newline and tab); its optional interval is milliseconds between character presses (default 50, minimum 30). Host layout and Caps Lock must match.

            
Lua runs for each queued Run or MIDI note-on. event.source is "web" or "midi"; event.channel, event.note and event.velocity are numbers; event.pressed is true. Web runs use the configured channel/note and velocity 127. state persists across triggers (32 named scalar values). Edits, cancellation/failure and restart reset state; USB loss does not globally reset non-keyboard scripts. millis() and epoch() read original trigger-time snapshots. value_type() inspects values; type() types text.

            
sound.play("clip.wav", 1.0), sound.stop_all(), midi.note_on(0,60,100), midi.note_off(0,60), midi.cc(0,1,64), midi.program(0,5), and midi.send(status,...) queue device actions. Sound must already be preloaded; MIDI goes to the controller, not the USB host. log("message") writes to device logs. No files, shell, network, or module loading. Lua guide, API reference and recipes (requires internet on your browser).

            
effects.enable(id, true), effects.toggle(id), effects.set(id, parameter, value) use existing effect IDs and actual parameter ranges (invalid values report runtime errors). volume.set(id, 0..100) and volume.adjust(id, -100..100) use routing thing IDs from GET /api/audio/volumes, not display names. 100% is unity gain; adjustments are percentage points clamped to 0..100. Device controls are runtime-only; routing automation is planned later.

            
Limits: 2,047 UTF-8 bytes, 64 actions, 256 typed characters (255 per type call), 60 seconds scheduled time, 10,000 instructions, 256 KiB Lua memory. Saving checks syntax; execution errors appear in device logs and here after Reload Macros. No actions or state updates from a failed evaluation are applied.

          

          

            

              
              
            

            

              
              
            

          

          
Leave both velocities at 0 for web-only macros with no default lighting. 0 turns the LED off; 1–127 selects your controller's velocity/color. Uses the global lighting output channel. MIDI-bound macro colors override sound/action colors on the same note; Dim Lights still applies. Lua light() requires an enabled MIDI binding and the selected controller connected, even for web Run. Without a binding it reports a runtime error; it temporarily overrides the bound pad.

Configuration Backup

          
Save all AudioX settings, routing, MIDI/lighting, effects, volumes, Bluetooth pairings, and soundboard audio in one .axb file. Save any pending UI edits first. Backups contain Bluetooth keys; keep them private.

          
          

            
            
          

          
Restore after reflashing to recover your setup. Restore replaces settings and sounds, then reboots. Firmware and boot files are not changed. Maximum backup size: 4 GiB; free device storage must fit the upload and extracted files.
