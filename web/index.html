Plugins

          
Plugins are native code that runs inside the audio engine. A malicious or faulty plugin can disrupt audio, read or damage device data, and its custom UI can show misleading controls. Install only .axm packages from authors you trust.

Scripts

          
Up to 16 Lua scripts, triggered by MIDI, audio events, or Run. Run uses the saved source.

          

            Device requirements
            
Keyboard output requires USB Keyboard enabled in Config and a connected host. MIDI and pad lighting require the selected controller. Sound, effects, and volume actions require neither connection.

          

          

            
            
          

          
          

          

            
            
          

          

            
            
          

          
          
Enter a channel and note, or select Learn MIDI Pad.

          

          

            

              Callbacks and state
              
Register a handler for each event:

              
hook("run", function(event)
  state.runs = (state.runs or 0) + 1
  log("Run " .. state.runs)
end)

hook("sound_finish", function(event)
  if event.sound == "intro.wav" then
    log("Intro finished")
  end
end)

              
Register hooks unconditionally at top level; place actions, configuration I/O, and event/state access inside handlers. Setup reruns for every event. Only scalar state fields persist between events, not across restart. Up to 32 handlers run in registration order. Run requires a run hook. MIDI hooks require a binding; for CC, Note specifies the controller number.

            

            
            
            

            

            
            

            

              Lua API quick reference and execution limits
            
Keyboard: tap("CTRL+A"), press("SHIFT+A"), release(), type("Text", 80). press replaces held keys; tap and type release them first. Completion or cancellation releases all keys. type uses US-layout ASCII; match the host layout and Caps Lock state. Typing interval: 50 ms default, 30 ms minimum. wait(ms) schedules a delay; light(velocity) sets the bound pad LED.

            
Events: note_on, note_off, cc, sound_start, sound_finish, device_connect, device_disconnect, run, boot, timer, config_change, ui. event.source identifies web, midi, audio, or device. Use event.sound or event.device for audio/controller events. Run supplies velocity 127. state holds 32 scalar fields; edits, cancellation, and restart may reset it. millis() and epoch() are trigger-time snapshots.

            
Saved scripts can expose native settings and buttons below. Settings save on change and queue config_change; buttons queue ui. Queued is not confirmation of execution. Text settings allow up to 127 UTF-8 bytes. Custom script_config settings, ui controls and storage do not require official configuration or system-management permission.

            
Output: sound.play("clip.wav", 1.0), sound.stop_all(), midi.note_on(0,60,100), midi.note_off(0,60), midi.cc(0,1,64), midi.program(0,5), midi.send(status,...). Clips must be preloaded. MIDI output targets the controller, not the USB host. log("message") writes to device logs. Shell, network, arbitrary file access, and module loading are unavailable. Lua API and examples (internet required).

            
Configuration: config.list(), config.read(name), config.write(name, text). Reads: 64 KiB/file. Writes replace the whole file: 4 KiB/write, 8 KiB total payload. Saving requires confirmation. Back up first: file contents are not format-validated and may require reload/restart. Pairing credentials are inaccessible. Avoid repeated writes and recursive sound triggers.

            
Processing: effects.enable(id, true), effects.toggle(id), effects.set(id, parameter, value). Use valid effect IDs and parameter ranges. volume.set(id, 0..100) and volume.adjust(id, -100..100) use IDs from GET /api/audio/volumes, not names. 100% is unity; adjustments are percentage points clamped to 0..100. These changes are runtime-only.

            
Per event: 17,408 UTF-8 source bytes, 128 actions, 1,024 typed characters (255/call), 60 seconds scheduled duration, 100,000 instructions, 1 MiB Lua memory. Registration and handlers share the budgets. Save validates registration without running handlers. Failed evaluation discards pending actions and state changes. Lua runs outside the audio thread. Reload Scripts or inspect logs for errors.

            

          

          

          Pad lighting
          

            

              
              
            

            

              
              
            

          

          
0 = off; 1–127 = controller color/velocity. Output uses the global lighting channel. Script colors take priority over sound/action mappings on the same note; Dim Lights overrides all colors. light() requires an enabled MIDI binding and connected controller, including for Run.
